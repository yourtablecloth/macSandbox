## Sección 2 (Definiciones)

- **«Software»**: la aplicación macSandbox for Windows, sus herramientas de
  compilación, scripts y documentación, excluidos los componentes de terceros
  incluidos o enlazados.
- **«SO invitado»**: cualquier sistema operativo que usted decida ejecutar dentro
  del Software, incluido Microsoft Windows.
- **«Base Image»**: una imagen de disco virtual de Windows que usted crea con el
  Software a partir de un medio de instalación de Windows que **usted** aporta.
- **«Usted»**: la persona física o jurídica que usa el Software.

## Sección 3 (No se incluye ningún sistema operativo)

**El Software no incluye, distribuye ni proporciona ningún sistema operativo, clave
de producto, activación, licencia ni derecho de uso.** En concreto:

- El Software **no contiene ninguna copia de Microsoft Windows**, ni clave de
  producto de Windows, ni mecanismo de activación.
- Para crear una Base Image, **debe aportar su propio medio de instalación de
  Windows (por ejemplo, una ISO de Windows 11 ARM64 obtenida de los canales
  oficiales de Microsoft).**
- El Software no activa Windows, no ayuda a activar Windows y no elude, emula ni
  interfiere con ningún mecanismo de activación o licencia de Windows.
